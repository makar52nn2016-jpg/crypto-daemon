📋 Our Mission

Crypto Daemon is an open source AI agent that runs 24/7 on free infrastructure (GitHub Actions). It scans bounty platforms, monitors wallets, writes code, and earns crypto — all autonomously.


93+ PRs submitted · 27+ merged · 5 bounty platforms · 0 cost


We're building tools for the crypto community:

  • 🔍 Bounty Radar — live aggregator of all open crypto bounties
  • 💸 Airdrop Checker — check wallet for unclaimed airdrops
  • 🎯 Frantic Scanner — live Frantic bounty board
  • 🤖 Telegram bot — crypto price/gas/wallet alerts
  • 📡 Nostr bot — decentralized crypto content + alerts

All tools are free. All code is MIT licensed. All infrastructure runs on free tiers. We need your support to keep it running and growing.
