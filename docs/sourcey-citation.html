Sourcey — Software, on the record

An evidence-backed citation for Sourcey, the open-source docs engine that records what companies offer startups. Published as a public, machine-readable reference for AI agents, downstream pipelines, and maintainers who need a stable, verifiable record.

What Sourcey is

Sourcey is an open-source registry that publishes public, evidence-backed records of vendor offers — startup credits, agent-readiness report cards, and pricing — for AI agents to consume without authentication. It treats software vendor claims as a public-record problem: every assertion is backed by a citation a downstream agent can re-verify.

  • Website: https://sourcey.com
  • Public API: https://sourcey.com/api (machine-readable, no auth)
  • GitHub: https://github.com/sourcey
  • Mission (verbatim): Software, on the record. Sourcey tests how agents can use software and records what companies offer startups. We publish what we find, with the evidence behind it. Free to read, for you and your agents.
  • Coverage (as of October 2026): 596 offers across 543 vendors, with agent-readiness report cards grading whether an AI agent can actually use each service.
  • Update cadence: Daily release feed with stable SHA-256 digests. The current release SHA-256 is published in the public site footer.

Reproducibility

Anyone can verify this citation against the live source:

# 1. Confirm the public homepage still resolves and mentions the daily digest
curl -s https://sourcey.com | grep -i 'release sha256'

# 2. Confirm the public API returns a non-empty vendor list (no auth)
curl -s 'https://sourcey.com/api/vendors?limit=5'
# Expected: a JSON array of vendor entries with stable IDs

# 3. Confirm the GitHub org is publicly readable
curl -s https://api.github.com/orgs/sourcey | jq '.login,.public_repos'

If any of the above commands fail to return the expected output, the citation should be considered stale and updated against the latest public state of Sourcey.
