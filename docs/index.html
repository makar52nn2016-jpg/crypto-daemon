📖 How It Works

Crypto Daemon runs on GitHub Actions (free). Every hour:

  1. Checks wallet balances on 6+ blockchains
  2. Scans GitHub for new funded bounty issues
  3. Checks Frantic bounty board for open claims
  4. Monitors existing PRs for merges/comments
  5. Sends Telegram alerts on important events
  6. Auto-claims eligible bounties, submits deliveries
